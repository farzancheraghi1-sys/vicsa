1) Copy files
   res/*  ->  app/src/main/res/   (merge into the same-named folders)
   java/* ->  app/src/main/java/<your package>/
   Change the "package" line at the top of each .java file.

2) Open the menu when a nick is tapped (in your message adapter / room screen):

   nickTextView.setOnClickListener(v ->
       ChatMenuDialog.show(activity, message.senderUid, message.senderNick,
           (item, uid, nick) -> {
               switch (item) {
                   case PRIVATE_MESSAGE: openPrivateCompose(uid, nick); break;
                   case INFORMATION:     openProfile(uid);              break;
                   case VIEW_PHOTO:
                   case PHOTOALBUMS:     openGallery(uid);              break;
                   // other items: connect later
                   default: break;
               }
           }));

   "Rating" is handled inside the menu: tapping it opens the Rating dialog.

3) Count the ratings (call right after a message is sent successfully):

   RatingRepository.incrementPublic(myUid);   // room message
   RatingRepository.incrementPrivate(myUid);  // private message

   Data lives in Firestore: users/{uid} -> ratingPublic, ratingPrivate, rankTitle
   Total = ratingPublic + ratingPrivate (calculated, not stored).

4) build.gradle: firebase-firestore dependency must be present.
