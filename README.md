# AVACS Clone (Android, Kotlin, Compose, Firebase)

1. In Firebase console: create project, add Android app with package `com.vicsa.avacs`,
   enable Authentication (Email/Password) and Firestore (test mode).
2. Download `google-services.json` and put it in the `app/` folder.
3. Upload this whole folder to a GitHub repo. Actions tab -> "Build APK" -> download `app-debug` artifact.
